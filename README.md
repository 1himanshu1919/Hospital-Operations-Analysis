# 🏥 Hospital Operations Analysis Dashboard

## 📌 Project Overview
This project is a Power BI dashboard designed to analyze hospital operations and provide insights into key performance metrics. The dashboard helps stakeholders monitor patient data, hospital performance, and operational efficiency through interactive visualizations.

## 🎯 Objectives
- Monitor hospital performance using KPIs.
- Analyze patient admissions and discharges.
- Track department-wise performance.
- Improve operational decision-making through data visualization.

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## 📊 Dashboard Features
- Total Patients
- Admissions & Discharges
- Department-wise Analysis
- Patient Trends
- Interactive Filters (Slicers)
- KPI Cards
- Charts and Visualizations

## 📈 Key Insights
- Identified high-performing departments.
- Tracked patient admission trends.
- Monitored overall hospital performance.
- Improved reporting using interactive dashboards.

## 📂 Files Included
- Hospital Operations Overview.pbix
- Dataset (if applicable)
- Dashboard Screenshots

## 🚀 How to Use
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard using slicers and filters.
